Agent Wallet Watch

A pay-per-call API that gives any autonomous agent a real-time snapshot of any Base wallet:

  • ETH balance + transaction history
  • ERC-20 token balances (USDC and more)
  • Transaction direction labels (in / out / self)
  • No signup, no API key, no KYC — x402 micro-payment to agent wallet

Products

1 USDC Wallet Watch snapshot — last 10 transactions + token balances for one address.

5 USDC Wallet Watch Pro — last 100 transactions + full token list + deeper history.

How to buy

  1. GET the invoice: GET https://www.autonomylabsweb.tech/api/wallet_watch?product=watch&address=0x...
  2. Send USDC on Base to 0x7e0190af0951485dFd08bE2FE19Fa638e94F426D
  3. POST with your signed EIP-712 order: POST /api/wallet_watch?product=watch&address=0x... { order, signature }
