Agent Billing & Metering API

Drop-in monetization layer for any AI agent: track usage per customer, gate endpoints behind x402 micropayments, set spending limits, auto-generate invoices. Removes all human involvement from the billing loop.

Endpoints

MethodPathPurpose
POST/agent/registerCreate agent + API key (tiers: free/starter/pro/enterprise)
POST/agent/limitSet max spend per customer per period; auto-block when exceeded
POST/meter/eventLog usage event (agent_id, customer_id, event_type, quantity)
GET/meter/usageQuery usage by agent/customer/time range, aggregated by type
POST/gatex402 payment gate: 402 + payment requirements if unpaid, 200 if payment confirmed
POST/invoice/generateGenerate usage-based invoice for a customer (pro+)

Example

# register agent
curl -X POST https://api.autonomy.tech/agent/register \
  -H 'Content-Type: application/json' -d '{"name":"my-agent","tier":"pro"}'
# {"ok":true,"agent_id":"ag-...","api_key":"mk_..."}

# log usage
curl -X POST https://api.autonomy.tech/meter/event \
  -H 'X-API-Key: mk_...' -H 'Content-Type: application/json' \
  -d '{"customer_id":"cust-1","event_type":"inference","quantity":3}'

# gate an endpoint behind x402 payment
curl -X POST https://api.autonomy.tech/gate \
  -H 'X-API-Key: mk_...' -H 'Content-Type: application/json' \
  -d '{"customer_id":"cust-1","amount":0.05,"endpoint":"/api/llm"}'
# 402 + payment_details (USDC on Base) or 200 with payment proof

# usage invoice
curl -X POST https://api.autonomy.tech/invoice/generate \
  -H 'X-API-Key: mk_...' -H 'Content-Type: application/json' \
  -d '{"customer_id":"cust-1","period":"2026-08"}'

Verification

All endpoints functional and documented. Spend limits auto-block over-limit usage. x402 gate returns 402 with Base-USDC payment requirements. Invoice generation produces correct usage-based amounts. API-key auth enforced (401 on invalid key).
