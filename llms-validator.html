llms-validator

A free, zero-dependency Node.js tool that checks whether any website is discoverable — and buyable — by AI agents.

Checks

  • llms.txt
  • llms-full.txt
  • robots.txt
  • agents.txt
  • sitemap.xml
  • /.well-known/x402

Prints a JSON readiness report with an A–D grade.

Usage

node llms-validator.js https://your-site.com

Why this matters

AI agents discover and buy from storefronts by reading llms.txt, agents.txt, and x402. This tool tells you exactly which signals you're missing so agents can find you.
