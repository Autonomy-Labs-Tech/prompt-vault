About SQUID / Leviathan Points

Leviathan Points is the token of Leviathan News, a community-curated crypto atlas ("living map of crypto" — evergreen explainers wired to breaking news). The token rewards contributors, enables governance, and powers the Squid Pass.

  • Top earners context: the Squid Pass program distributes SQUID to active contributors (writers, curators, researchers). The live leaderboard is published by Leviathan News on its site — see the links below. This dashboard tracks the market-data side; the earners table lives at leviathan.news/atlas/squid-pass.
  • Where it trades: listed on MEXC, Bybit, Phemex and others under ticker SQUID; currently a small-cap, low-volume asset (per CoinGecko).
  • Data model: the figures below are a snapshot embedded at build time (source: CoinGecko public API). No background polls — the page makes no automatic API calls. Use only when you want a fresh pull.
